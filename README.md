# 我的工作台

一个给大学生的本地个人工作台：**课程表 + 待办清单 + 每日记录**，纯原生 HTML/CSS/JS，零依赖、零安装。

**在线地址**：https://09-25.github.io/workbench/

## 安装成 App

- **Android**：Chrome 打开网址 → 右上角 ⋮ →「添加到主屏幕 / 安装应用」→ 桌面出现独立图标，全屏运行
- **iPhone**：Safari 打开网址 → 分享按钮 →「添加到主屏幕」
- **电脑**：Chrome/Edge 地址栏右侧「安装」图标，或直接固定标签页

## 电脑 ⇄ 手机 云同步

1. 两台设备都打开上面的网址
2. 各自：设置 → 云同步 → 点「去生成 Token →」（登录同一 GitHub 账号，页面已预勾 gist 权限）→ Generate token → 复制 `ghp_` 开头的串
3. 粘贴到 Token 框 → 「连接并开始同步」——Gist 自动创建/自动汇合，之后所有改动几秒内自动推到云端，其他设备最多 30 秒自动合并
4. Token 只存在各自设备本地，不上传；同步数据存在你的 GitHub 私密 Gist 里

本地双击 `index.html` 照常可用（云同步和安装需走网址版）。

## 怎么用（本地版）

双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge，固定标签页当浏览器主页更顺手）。

## 从教务系统导入课表（陕西理工大学 EAMS）

课程表页 →「📥 从教务导入」，三种方式任选：

1. **网页粘贴**：登录 `jwgl.snut.edu.cn/eams/ssoLogin.action`（校园网）→ 打开「我的课表」→ `Ctrl+A` 全选 → `Ctrl+C` → 回到工作台粘贴框 `Ctrl+V`
2. **文件导入**：教务课表网页右键「另存为」`.html` 文件，拖进导入框（自动识别 GBK/UTF-8 编码）
3. **Excel 粘贴**：如果能导出 Excel，打开后全选复制再粘贴

解析后先出**预览清单**（可逐条剔除识别错的），再选「合并导入」或「替换整个课表」。支持识别：双节连排自动合并、一格多门课、`1-17周` / `1-15周(单)` / 单双周 / `第3周` 等周次写法、教师中英文名、教室。同名课自动同色。

## 功能

| 页面 | 说明 |
|------|------|
| 概览 | 问候语 + 实时时钟 + 第几周，今天的课（进行中高亮）、今日待办、考试倒计时、打卡总览、常用网站入口 |
| 课程表 | 周一~周日 × 五大节网格；支持**任意周次区间/单双周/指定周**（如 `3-10周(单)`），非本周课程自动淡显 |
| 待办 | 优先级 + 截止日期，逾期标红；筛选：未完成 / 今天 / 全部 / 已完成 |
| 日志 | 选任意日期记录「今天干了啥」（自动记时间）+ 习惯打卡（连续天数）+ 随手记 |
| 设置 | 称呼、学期开始日、上课时间、倒计时管理、常用入口、纸间/夜灯主题 |

## 数据与备份

- 所有数据保存在**本机浏览器 localStorage** 里，不上传任何服务器。
- 换电脑 / 换浏览器前，在「设置 → 数据」里**导出备份**（JSON 文件），到新环境**导入**即可。
- 首次打开自带一份示例数据，在「设置 → 清空全部数据」即可从零开始。
