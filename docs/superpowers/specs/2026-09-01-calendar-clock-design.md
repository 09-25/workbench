# 概览日历时钟设计

## 目标

将概览顶部的时间区域升级为 C 版“月历便签”：在保留实时钟和现有问候、上课状态的同时，加入公历日期、农历、节气或节日，以及当前月份的迷你月历。

## 页面与布局

- 改动范围仅限概览页 `.hero`，不改数据结构、同步、课程表或日志页。
- 左侧保留问候、实时 `HH:MM:SS`、学期周次和上课状态。
- 右侧新增可视化日历卡：显示年份与月份、周一至周日标题、当月日期；今天使用主题强调色圈出。
- 时间下方显示完整公历日期与农历信息；节日优先于节气显示。农历和节气均复用当前 `calendarLine()` 相关计算，不增加网络请求。
- 桌面端月历卡固定在 hero 右侧；窄屏端仍保持单行信息优先，月历缩小并移至可用空间内，不产生横向滚动。

## 更新与边界

- 时钟每秒刷新；跨日时同时刷新日期、农历、月历、课程和待办。
- 月历按用户设备本地日期计算，月份边界和周日/周一对齐正确。
- 节气或农历算法不在本次改动中修复；已存在的农历偏移问题保持为独立待修事项，避免混入布局变更。

## 验证

1. 新增浏览器测试，先验证概览存在月历、当日高亮和日期信息。
2. 在实现前运行测试并确认因新元素缺失而失败。
3. 实现后运行新测试及既有功能、对抗和移动端测试；确认无浏览器 JavaScript 错误、无横向溢出。
