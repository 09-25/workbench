# 小机器人「指令中枢」升级设计

## 目标

把现有右下角自然语言速记机器人升级为更适合手机使用的「指令中枢」：打开后优先呈现可直接执行的快捷操作，同时保留文字输入和语音输入。功能必须离线可用，数据继续写入现有本地状态，不新增服务器依赖。

## 已确认范围

第一版快捷功能固定为：

1. **看今天课表**：展示当天课程名称、上课时间和教室；没有课程时显示空闲提示。
2. **快速记待办**：在机器人面板内打开短输入框，保存到现有待办列表，并立即反馈保存结果。
3. **开始专注**：默认启动 25 分钟专注计时，支持暂停、继续、结束，并在机器人面板内显示状态。

已有的自然语言解析、语音输入、识别结果确认卡继续保留，作为快捷按钮下方的备用入口。

### 课程卡片个性化

- 每门课程可以单独设置颜色和卡片样式，不改变其他课程。
- 默认采用 **A · 柔和填充**：浅色底、左侧色条、轻阴影，保持当前米白主题的柔和观感。
- 课程卡保留三种样式预设：柔和填充、实色强调、线框简洁；颜色从有限的高对比预设中选择，避免文字难以阅读。
- **上课时间和教室是重点信息**：字号和字重高于普通辅助信息，使用更深的文字颜色，并以独立标签/分组显示；课程名称保持第一层级，教师和周次作为较弱的辅助信息。
- 在课程编辑弹窗中增加颜色和样式选择，保存后立即更新当前课表并写入本地状态。

## 交互与视觉

- 点击右下角机器人后，展开紧凑的指令中枢面板；再次点击或 Android 返回键关闭。
- 面板顶部显示机器人头像、标题和状态标签（空闲、执行中、专注中）。
- 中部为三个大按钮，分别使用明确图标、中文名称和一句短说明。
- 底部保留文字输入、麦克风按钮和发送按钮。
- 面板采用深色底、米黄色文字/按钮高亮，与现有米白背景形成清晰对比；按钮提供 hover/pressed/disabled 状态和轻量过渡动画。
- 手机端面板宽度不超过视口，桌面端保持现有浮层位置；输入和按钮不遮挡底部导航。

## 组件与数据流

### Command Hub UI

负责渲染快捷按钮、状态标签和专注计时显示。通过 `data-action` 事件委托触发命令，不直接修改课程或待办数据。

### Today Schedule Command

读取当前日期、当前周和现有课程数组，复用课表筛选逻辑生成只读摘要，渲染在机器人消息区；不改变课表。

### Quick Todo Command

读取面板内输入，调用现有待办新增/持久化路径；成功后清空输入并显示反馈，空输入和异常情况显示可恢复提示。

### Focus Timer Command

维护 `idle/running/paused/done` 四种状态和剩余秒数。计时器只在前台运行，页面刷新后不承诺恢复；暂停和结束均清理 interval，避免重复计时。

### Existing Bot Parser

保留现有自然语言和语音输入。快捷命令与解析器共享消息渲染和反馈方法，避免重复创建待办/课程逻辑。

## 错误处理与边界

- 没有课程：显示“今天没有安排课程”，不视为错误。
- 待办输入为空：按钮保持可用但提交时提示补充内容，不写入空记录。
- 专注计时重复点击：运行中按钮变为暂停/继续，不启动第二个 interval。
- 语音不可用或权限被拒绝：继续显示已有的文字输入替代提示。
- 面板空间不足：快捷按钮换行，消息区可滚动，输入区固定在底部。

## 验证计划

- 新增单元/静态回归测试，覆盖：三项快捷按钮存在、按钮命令映射正确、专注状态不会创建重复计时器、空待办不会写入。
- 保留并运行现有课表周次、节次、教室、首页布局和欢迎弹窗测试。
- 使用 390×844 移动视口做一次浏览器截图检查，确认面板不溢出底部导航；再执行 `npm run build:web` 和 Android debug 构建。

## 非目标

- 不接入 AI API，不引入服务器或账号系统。
- 不重写现有自然语言解析器和数据模型。
- 不在本轮增加云端提醒、后台计时或推送通知。
