# Android 本地版设计

## 目标

将现有“我的工作台”原生网页应用打包成 Android APK，让其他用户直接安装在自己的手机上使用。第一阶段不建设用户数据服务器、不要求账号、不依赖联网；课程、待办、日志、习惯、倒计时以及后续截图识别均在设备本地完成。

## 产品范围

Android 8.0 及以上，面向个人使用。APK 包含现有 HTML/CSS/JS、图标和离线资源；用户首次打开进入空白工作台或通用示例数据，不携带作者的个人课表和日志。

本阶段包含：

- 现有概览、课表、待办、日志、习惯、倒计时和自然语言小助手；
- 本地 localStorage 数据存储；
- JSON 数据导出与导入；
- Android 返回键：优先关闭弹窗/小助手，其次返回概览页，最后退出页面；
- APK 名称、图标、启动页、版本号和隐私说明；
- 本地文件选择及图片读取能力，为后续截图识别预留入口。

本阶段不包含：

- 账号、云同步或作者服务器；
- GitHub Token/Gist 配置；
- iOS 安装包；
- 推送通知、桌面小组件和应用商店自动更新。

## 技术架构

使用 Capacitor Android 作为轻量原生外壳，网页资源直接随 APK 打包。Android 原生层只负责生命周期、返回键、文件选择和应用元数据；业务逻辑继续位于现有 `app.js`，避免重写成熟功能。

```text
Android APK
├── Capacitor WebView
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── Android 文件选择桥接
└── 本地应用存储
```

数据流保持本地优先：

```text
用户操作 → app.js → localStorage
导出     → JSON 文件（用户选择保存位置）
导入     → 用户选择 JSON → normalize() → localStorage
截图     → 手机图片 → 本地 OCR（后续阶段）→ 预览 → 用户确认
```

## 隐私与数据安全

- 默认不发起数据上传请求；公开版移除 GitHub Gist 同步入口和 Token 文案。
- 应用内显示“数据只保存在本机”的说明，并提供导出备份。
- 导出文件由用户主动保存和传输；应用不读取用户未选择的文件。
- 后续 OCR 使用随 APK 提供的本地模型，截图不离开设备。

## 交互与错误处理

- 首次打开没有数据时显示清晰的空状态和“添加第一门课”入口。
- Android 返回键按“关闭当前层级 → 回到概览 → 交给系统退出”的顺序处理。
- 导入文件不是合法 JSON、缺少必要字段或读取失败时显示中文提示，保留当前数据不覆盖。
- 文件权限被拒绝、图片格式不支持或 OCR 失败时显示可操作提示，允许回到手动录入。
- APK 内资源加载失败时显示离线错误页，不展示空白白屏。

## 发布与更新

- 小范围测试：生成签名 APK，通过网盘、微信或 QQ 分发。
- 每次发布递增版本号，提供简短更新说明；用户通过覆盖安装升级，本地数据保持不变。
- 用户须知说明“安装包来源”和“数据存储位置”，避免把测试 APK 与正式版混淆。
- 用户量稳定后再评估 Google Play 或国内应用市场，不改变本地数据架构。

## 验证

1. 网页回归：运行现有功能、对抗、导入和移动端测试，确认打包前网页行为不回退。
2. Android 构建：在干净环境生成 debug APK 和 release APK，确认资源完整、版本号正确。
3. 真机冒烟：安装、首次启动、切页、返回键、增删课程、导出/导入 JSON、断网启动。
4. 数据安全：拦截网络请求确认启动和普通操作不上传业务数据；卸载前导出、重装后导入成功。
5. 回归验收：截图识别尚未实现时不显示误导性入口；所有失败路径都有中文提示。
